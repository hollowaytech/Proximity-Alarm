# Proximity-Alarm
## Proximity-Alarm built and programmed using C++.
# Features 🛠️
- Input/output and/for pin mappings
- Loop function that checks distance with ultrasonic sensor
- Conditions that check if alarm should go off or not
# Hardware ⚙️
- Arduino board (any is fine)
- Two LEDs (one red, one green)
- Two 220ohm resistors
- Ultrasonic distance sensor
- Jumper wires
